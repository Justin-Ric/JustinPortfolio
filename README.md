# Justin Ric Siachongco — Portfolio

A responsive, single-page React + Vite portfolio based on the Home, About, Projects, Skills, and
Contact designs. Scroll between sections or use the navigation to jump to a section; the active
navigation item follows the section in view. Sections reveal as you scroll, and the contact form
opens a prefilled email in your default mail application.

## Getting started

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```
